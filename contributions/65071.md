## 문제 내용

`internalBinding('internal_only_v8')`가 반환하는 네이티브 바인딩 객체의 인터페이스를 타입으로 정의하여 정적 타입 검사와 자동완성을 지원하고자 했습니다.

## 해결 과정과 검증

```js
const {
  queryObjects: _queryObjects,
} = internalBinding('internal_only_v8');
```

`internal_only_v8.cc`
```cpp
SetMethod(context, target, "queryObjects", QueryObjects);
```

`internal_only_v8` 네이티브 코드에서 JS 코드로 연결하여 사용하는 메서드는 `queryObjects` 하나였습니다. 이에 대해 함수의 정의 부분과 사용 부분을 파악하여 타입을 정의하였습니다.

```cpp
void QueryObjects(const FunctionCallbackInfo<Value>& args) {
  CHECK_EQ(args.Length(), 1);

  if (!args[0]->IsObject()) {
    args.GetReturnValue().Set(Array::New(isolate));
    return;
  }

  std::vector<Global<Object>> out;

  args.GetReturnValue().Set(Array::New(isolate, result.data(), result.size()));
}
```
매개변수는 하나이지만 객체 여부를 검사하기 때문에 어떤 타입의 매개변수가 오는지 정의하기가 어려워 `unknown`을 사용하였습니다.

반환값은 `Global<Object>`를 통해 JS 객체 타입의 V8 객체를 반환하는데 이를 `std::vector<>`에 담아 반환하기 때문에 `Object[]`로 반환 타입을 잡았습니다.

```js
export interface InternalOnlyV8Binding {
  queryObjects(prototype: unknown): object[];
}
```
