## 문제 내용

`internalBinding('credentials')`가 반환하는 네이티브 바인딩 객체의 인터페이스를 타입으로 정의하여 정적 타입 검사와 자동완성을 지원하고자 했습니다.

## 해결 과정과 검증

JS 코드 내에서 `credentials`를 활용하는 부분은 다음과 같았습니다.

```js
const { getTempDir } = internalBinding('credentials');
const credentials = internalBinding('credentials');
if (credentials.implementsPosixCredentials) {
  process.getuid = credentials.getuid;
  process.geteuid = credentials.geteuid;
  process.getgid = credentials.getgid;
  process.getegid = credentials.getegid;
  process.getgroups = credentials.getgroups;
}
const { safeGetenv } = internalBinding('credentials');
```

`credentials`가 정의된 네이티브 코드는 `node_credentials.cc` 파일에서 확인할 수 있었습니다.

```c++
static void Initialize(...) {
  SetMethod(context, target, "safeGetenv", SafeGetenv);
  SetMethod(context, target, "getTempDir", GetTempDir);

#ifdef NODE_IMPLEMENTS_POSIX_CREDENTIALS
  Environment* env = Environment::GetCurrent(context);
  Isolate* isolate = env->isolate();

  READONLY_TRUE_PROPERTY(target, "implementsPosixCredentials");
  SetMethodNoSideEffect(context, target, "getuid", GetUid);
  SetMethodNoSideEffect(context, target, "geteuid", GetEUid);
  SetMethodNoSideEffect(context, target, "getgid", GetGid);
  SetMethodNoSideEffect(context, target, "getegid", GetEGid);
  SetMethodNoSideEffect(context, target, "getgroups", GetGroups);

  if (env->owns_process_state()) {
    SetMethod(context, target, "initgroups", InitGroups);
    SetMethod(context, target, "setegid", SetEGid);
    SetMethod(context, target, "seteuid", SetEUid);
    SetMethod(context, target, "setgid", SetGid);
    SetMethod(context, target, "setuid", SetUid);
    SetMethod(context, target, "setgroups", SetGroups);
  }
```

`READONLY_TRUE_PROPERTY`는 `true` 값을 갖는 읽기 전용의 속성을 정의하는 것이기 때문에 `implementsPosixCredentials` 속성은 true 값을 갖는다는 것을 알 수 있습니다.

```c++
static void SafeGetenv(const FunctionCallbackInfo<Value>& args) {
  CHECK(args[0]->IsString());
  ...
  std::string text;
  if (!SafeGetenv(*strenvtag, &text, env)) return;
  Local<Value> result;
  if (ToV8Value(isolate->GetCurrentContext(), text).ToLocal(&result)) {
    args.GetReturnValue().Set(result);
  }
}
```

`SafeGetenv`의 매개변수는 하나이며 `string`의 값을 받는다는 것을 알 수 있습니다.
또한 조건에 따라 값을 `string`으로 변환하여 반환하거나 반환하지 않고 함수를 종료할 수 있습니다.

```c++
static void GetTempDir(const FunctionCallbackInfo<Value>& args) {
  std::string dir;

  // Try TMPDIR, TMP, and TEMP in that order.
  if (!get_env("TMPDIR") && !get_env("TMP") && !get_env("TEMP")) {
    return;
  }

  Local<Value> result;
  if (ToV8Value(isolate->GetCurrentContext(), dir).ToLocal(&result)) {
    args.GetReturnValue().Set(result);
  }
}
```
따로 매개변수를 받아오지 않고 조건에 따라 string 혹은 반환하지 않고 함수를 종료합니다.

```c++
static void GetUid(const FunctionCallbackInfo<Value>& args) {
  args.GetReturnValue().Set(static_cast<uint32_t>(getegid()));
}
```
`getuid`, `geteuid`, `getgid`, `getegid`는 모두 `uint32` 타입의 값을 반환하고 js에서는 `number` 타입으로 반환하게 정의할 수 있습니다.

```c++
static void SetGid(const FunctionCallbackInfo<Value>& args) {
  CHECK_EQ(args.Length(), 1);
  CHECK(args[0]->IsUint32() || args[0]->IsString());

  if (gid == gid_not_found) {
    // Tells JS to throw ERR_INVALID_CREDENTIAL
    args.GetReturnValue().Set(1);
  } else if (setgid(gid)) {
    env->ThrowErrnoException(errno, "setgid");
  } else {
    args.GetReturnValue().Set(0);
  }
}
```
`setuid`, `seteuid`, `setgid`, `setegid`는 string 혹은 number의 값을 매개변수로 받고 1, 0 중 하나의 값을 반환한다는 것을 알 수 있습니다.

```c++
static void GetGroups(const FunctionCallbackInfo<Value>& args) {
  std::vector<gid_t> groups(ngroups);

  ngroups = getgroups(ngroups, groups.data());
  groups.resize(ngroups);
  gid_t egid = getegid();
  if (std::ranges::find(groups, egid) == groups.end()) groups.push_back(egid);

  Local<Value> result;
  if (ToV8Value(env->context(), groups).ToLocal(&result)) {
    args.GetReturnValue().Set(result);
  }
}
```
`gid_t`는 `int`에 해당하며 `std::vector<gid_t>`를 통해 숫자 타입의 배열을 선언하여 반환하는 것을 알 수 있습니다.

```c++
static void InitGroups(const FunctionCallbackInfo<Value>& args) {
  CHECK_EQ(args.Length(), 2);
  CHECK(args[0]->IsUint32() || args[0]->IsString());
  CHECK(args[1]->IsUint32() || args[1]->IsString());

  if (user == nullptr) {
    // Tells JS to throw ERR_INVALID_CREDENTIAL
    return args.GetReturnValue().Set(1);
  }

  if (extra_group == gid_not_found) {
    if (must_free) free(user);
    // Tells JS to throw ERR_INVALID_CREDENTIAL
    return args.GetReturnValue().Set(2);
  }

  args.GetReturnValue().Set(0);
}
```

총 2개의 매개변수를 받고 두 매개변수 모두 number 혹은 string값이며 조건에 따라 0, 1, 2를 반환한다.

```c++
static void SetGroups(const FunctionCallbackInfo<Value>& args) {
  CHECK_EQ(args.Length(), 1);
  CHECK(args[0]->IsArray());

  Local<Array> groups_list = args[0].As<Array>();
  size_t size = groups_list->Length();
  MaybeStackBuffer<gid_t, 64> groups(size);

  for (size_t i = 0; i < size; i++) {
    Local<Value> val;
    if (!groups_list->Get(env->context(), i).ToLocal(&val)) {
      // V8 will have scheduled an error to be thrown.
      return;
    }
    gid_t gid = gid_by_name(env->isolate(), val);

    if (gid == gid_not_found) {
      // Tells JS to throw ERR_INVALID_CREDENTIAL
      args.GetReturnValue().Set(static_cast<uint32_t>(i + 1));
      return;
    }

    groups[i] = gid;
  }

  int rc = setgroups(size, *groups);

  if (rc == -1) return env->ThrowErrnoException(errno, "setgroups");

  args.GetReturnValue().Set(0);
}
```

배열로 매개변수를 받으며 `gid_by_name()` 내부에서 숫자나 문자를 받아서 숫자를 반환하게 한다.
이 후 성공하면 0을 반환하지만 반복문 내 `i + 1`을 반환하여 숫자를 반환할 수 있다.

최종적으로 다음과 같이 `credentials.d.ts`를 작성할 수 있었습니다.

```ts
export interface CredentialsBinding {
  implementsPosixCredentials?: true;
  safeGetenv(key: string): string | undefined;
  getTempDir(): string | undefined;

  getuid?(): number;
  geteuid?(): number;
  getgid?(): number;
  getegid?(): number;
  getgroups?(): number[];

  initgroups?(user: string | number, extraGroup: string | number): 0 | 1 | 2;
  setegid?(id: string | number): 0 | 1;
  seteuid?(id: string | number): 0 | 1;
  setgid?(id: string | number): 0 | 1;
  setuid?(id: string | number): 0 | 1;
  setgroups?(groups: Array<string | number>): number;
}

```
